# Painted sprite redraw

Working baseline `d9e725f`. The former production sprites were drawn into Phaser Canvas atlases by `shadow-art.js`, `campaign-art.js`, `prototype-sprites.js`, `ultimate-enemies.js`, `campaign-boss-art.js`, `prototype-titan.js`, and `legends-bosses.js`. Legacy comparison-mode actor drawings live in `hero-art.js` and `art.js`. The production renderer now composes painted raster layers from the six WebP packs in `public/sprites/painted`. Each pack contains twelve trimmed parts. `src/game/rendering/painted-parts.json` records the source rectangles.

All five heroes use the new articulated raster rig. The outfits use colored material variants and the alternate weapons carry distinct raster silhouettes. The 31 campaign enemy types, Brambleback presentation, and three arena opponents have their own raster recipes. Each of the eight boss designs uses painted anatomy and armor. Biome tint is applied during compositions and the scene light rig continues to derive its normal maps from the completed raster frames. The HUD badges and several effects also use the painted packs. Enemy movement, health, attack windows, and level data continue to come from the existing controllers.

| Comparison | Frame | Previous source | Redrawn source |
| --- | --- | ---: | ---: |

The exported comparison PNGs read directly from the Phaser atlas before lighting. Both columns use the same logical sprite scale. Run `node test/sprite-art-browser.mjs` with `PIXEL_BEFORE_URL` pointing to a local build of the baseline and `PIXEL_TEST_URL` pointing to the review build. Set `PIXEL_SPRITE_REVIEW` to the output directory. `test/sprite-coverage-browser.mjs` inspects the painted atlases used in each of the 60 stages.

## Performance on the Windows test computer

Both builds used the same Edge viewport and input workload within each harness.

| Workload | Previous FPS | Redrawn FPS | Delta |
| --- | ---: | ---: | ---: |
| Desktop, Verdant Hills and Thunder Titan | 60.0 | 60.0 | 0.0 |
| Mobile emulation, Verdant Hills and Thunder Titan | 60.0 | 60.0 | 0.0 |
| 4× CPU throttle, Verdant Hills | 52.1 | 48.2 | −3.9 |
| 4× CPU throttle, Thunder Titan | 54.8 | 55.4 | +0.6 |
| 4× CPU throttle, Forgotten Swamp stress fixture | 60.0 | 43.2 | −16.8 |
| Desktop, six-enemy Survival fixture | 60.0 | 59.5 | −0.5 |

The 4× Eclipse Emperor sample reached 53.4 FPS with seven frames of at least 50 ms. The default hero's estimated atlas backing grew from 22.76 to 49.22 MiB. This measures the raster atlas alone. The six-enemy Survival sample had zero frames of at least 50 ms on either build. The benchmarks use desktop browser emulation for phones.

## Coverage

The production campaign runner started with a fresh profile and reached Victory through normal keyboard input. It cleared all 60 stages and observed three attack patterns in each of the eight boss fights. The roster browser audit found 44 biome-specific enemy atlases spanning the 31 campaign types and three additional encounters. Electron loaded all 60 stages offline and preserved saves on relaunch. Browser checks exercised retry and finisher states, keyboard input, multitouch, and eleven responsive layouts.

## Generation provenance

The six source PNGs were created with the built-in ImageGen tool. Each was 1448 × 1086 px on transparent backing. The delivered source plates were cropped and packed into 1024 × 768 transparent WebP sheets. `hud.webp` is a 256 × 128 strip derived from the eight HUD assets in `ui.webp`.
